# JavaScript Fundamentals

Core JavaScript concepts used throughout frontend development.

## Topics Covered

- Variables: `let`, `const`
- Operators and type coercion
- Conditions and logical operators
- Functions
- Arrays and basic array operations
- `for...of` loops
- `map()`, `filter()`, `reduce()`
- Arrays of objects
- Destructuring
- Spread operator
- Rest parameters
- Arrow functions
- String methods
- `find()`, `some()`, `every()`
- `includes()`, `indexOf()`, `join()`
- Object property shorthand
- Function scope
- Closures
- Truthy and falsy values
- `||` vs `??`
- Optional chaining
- Default parameters

## Purpose

Build a strong JavaScript foundation before moving into DOM manipulation, asynchronous JavaScript, APIs, and React.
