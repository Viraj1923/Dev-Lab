# DOM & Events

Manipulating HTML elements and responding to user interactions with JavaScript.

## Topics Covered

- Selecting elements with `querySelector()`
- Selecting multiple elements with `querySelectorAll()`
- `innerHTML`
- `textContent`
- Input `.value`
- Changing styles
- `createElement()`
- `append()`
- `appendChild()`
- Removing elements
- DOM traversal
- `classList.add()`
- `classList.remove()`
- Click events
- Event objects and `event.target`
- Input events
- Form submission
- `preventDefault()`

## Mini Project

Built a User Card application that accepts a name and age from a form and dynamically creates user cards in the DOM.

## Purpose

Understand how JavaScript interacts with HTML and handles user-driven events before moving to component-based UI development with React.
