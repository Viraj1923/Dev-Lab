# Fetch & APIs

Working with external APIs using the Fetch API.

## Topics Covered

- What an API is
- `fetch()`
- Handling the `Response` object
- `response.json()`
- `response.ok`
- HTTP error handling
- GET requests
- Query parameters
- `URLSearchParams`
- POST requests
- Request headers
- `JSON.stringify()` for request bodies
- `async/await` with Fetch
- `try...catch`

Learn how frontend applications communicate with backend services and external APIs.
