# Arrays & Objects

Working with real-world data using JavaScript arrays and objects.

## Topics Covered

- `map()` with arrays of objects
- Object spread for creating updated objects
- `filter()` + `map()`
- `reduce()` with objects
- `Object.entries()`
- Sorting arrays of objects
- `slice()` vs `splice()`
- Method chaining
- `filter()` + `reduce()`
- `Object.keys()`
- `Object.values()`
- `Object.entries()`
- `for...in`
- `Object.fromEntries()`
- Transforming object values

## Purpose

Practice transforming, filtering, calculating, sorting, and iterating over the data structures commonly used in frontend applications.
