# Modules, JSON & Error Handling

JavaScript modules, JSON data conversion, and handling runtime errors safely.

## Topics Covered

- Named exports and imports
- Default exports and imports
- `JSON.stringify()`
- `JSON.parse()`
- `try...catch`
- `throw new Error()`
- `finally`

## Purpose

Learn how JavaScript code can be organized into modules, how data is converted between JavaScript objects and JSON, and how errors can be handled without crashing the application flow.
