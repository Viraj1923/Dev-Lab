# Functions, Scope & Closures

JavaScript functions and the concepts that control how functions access and preserve data.

## Topics Covered

- Function expressions
- Callback functions
- Higher-order functions
- Global, function, and block scope
- Lexical scope
- Closures
- Closures with private state

## Practice

Implemented callbacks and higher-order functions using custom operations, then practiced scope and closure examples including independent counters.

## Purpose

Understand how functions work as values, how scope determines variable access, and how closures preserve state.
