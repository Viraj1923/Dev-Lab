# JavaScript — Phase 1

> **Frontend Development Journey · Phase 1**

A structured JavaScript learning phase focused on building a strong foundation for modern frontend development.  
This phase covers core JavaScript, DOM manipulation, asynchronous programming, APIs, and practical mini-projects.

---

## 🎯 Phase Goal

Build enough practical JavaScript knowledge to confidently move into **React** and modern frontend development.

The focus throughout this phase was on:

- Understanding JavaScript fundamentals
- Working with arrays and objects
- Writing reusable functions
- Understanding modern JavaScript syntax
- Manipulating the DOM
- Handling asynchronous operations
- Working with APIs
- Building small browser-based projects

## 🛠️ Skills Covered

### Core JavaScript

- Variables and data types
- Operators and type coercion
- Conditions and loops
- Functions and arrow functions
- Arrays and objects
- String methods
- Truthy / falsy values
- Scope and closures

### Array & Object Operations

- `map()`
- `filter()`
- `reduce()`
- `find()`
- `some()`
- `every()`
- `slice()`
- `splice()`
- `Object.keys()`
- `Object.values()`
- `Object.entries()`
- `Object.fromEntries()`
- Array/object sorting
- Object transformations

### Modern JavaScript

- Ternary operator
- Short-circuiting with `&&`
- Nullish coalescing `??`
- Optional chaining `?.`
- Default parameters
- Destructuring
- Spread operator
- Rest parameters

### Browser & DOM

- `querySelector()`
- `querySelectorAll()`
- `textContent`
- `innerHTML`
- Input `.value`
- `createElement()`
- `appendChild()`
- Element removal
- DOM traversal
- `classList`
- Click events
- Input events
- Form submission
- `preventDefault()`

### Asynchronous JavaScript

- Synchronous vs asynchronous execution
- `setTimeout()`
- Promises
- Promise states
- `.then()`
- `.catch()`
- `.finally()`
- Promise chaining
- `async`
- `await`
- `try/catch` with asynchronous code

### APIs

- Understanding APIs
- `fetch()`
- GET requests
- POST requests
- Request headers
- JSON request bodies
- `response.json()`
- `response.ok`
- Query parameters
- `URLSearchParams`
- HTTP error handling

## 🚀 Mini Projects

### 1. Todo List

A simple task manager built with DOM manipulation and events.

**Features:**
- Add tasks
- Mark tasks as completed
- Delete tasks
- Input validation

**Concepts:** DOM, events, dynamic elements, `classList.toggle()`

---

### 2. Character Counter

A small utility that counts characters while the user types.

**Concepts:** input events, `.value`, string `.length`, DOM updates

---

### 3. API User Search

A browser application that fetches user information from an external API.

**Features:**
- Search user by ID
- Display name
- Display email
- Display city
- Handle API errors

**Concepts:** Fetch API, `async/await`, JSON, error handling, DOM manipulation
