# JavaScript Mini Projects

Small projects built using JavaScript to practice DOM manipulation,
events, Fetch API, and async/await.

## Projects

1. Todo List
   - DOM manipulation
   - Events
   - Dynamic elements
   - Delete and complete tasks

2. Character Counter
   - Input events
   - String length
   - DOM updates

3. API User Search
   - Fetch API
   - Async/await
   - Error handling
   - DOM manipulation
