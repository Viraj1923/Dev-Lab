# JavaScript Mini Projects

Small projects combining the JavaScript concepts learned throughout Phase 1.

## Projects

### 1. Todo List

Practiced:

- DOM manipulation
- Click events
- Dynamic element creation
- `classList.toggle()`
- Removing elements
- Input validation

Features:

- Add tasks
- Mark tasks as completed
- Delete tasks

### 2. Character Counter

Practiced:

- Input events
- Reading `.value`
- String `.length`
- Updating the DOM

### 3. API User Search

Practiced:

- Fetch API
- `async/await`
- `response.ok`
- Error handling
- Dynamic DOM updates
- Nested API data

Features:

- Search a user by ID
- Display name, email, and city
- Handle invalid API responses
