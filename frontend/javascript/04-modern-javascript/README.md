# Modern JavaScript

Modern JavaScript syntax and patterns commonly used in frontend and React development.

## Topics Covered

- Ternary operator
- Short-circuiting with `&&`
- Nullish coalescing (`??`)
- Default parameters
- Object destructuring
- Destructuring with renaming
- Destructuring in function parameters
- Spread operator
- Rest parameters

## Purpose

Become comfortable with concise JavaScript syntax used heavily in modern frontend codebases and React applications.
